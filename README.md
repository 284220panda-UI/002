# 谁是你的对象 Who Is Your Date — Playable Demo

一款现代都市日常向的 AVG / 视觉小说游戏 Demo：对话驱动 + 证据收集 + 多结局。

两位主角：林夏（独立摄影师）与 周砚川（工程师）。通过提问与观察证据推进剧情。
